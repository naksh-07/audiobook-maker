# Curated CC0 & Public Domain Sound Effects (SFX) Library

This directory houses lightweight, royalty-free audio cues and sound effects for dramatized audiobook production.

## Storage Budget & Footprint
- Capped at **< 15 MB** total to keep agent memory, disk footprint, and repository synchronization minimal.
- All files are licensed under **CC0 1.0 Universal** (Public Domain) or **MIT**.

## Available Fallbacks
- In addition to local audio files, `soundscape.py` features **Procedural FFmpeg Audio Synthesis** for:
  - `wind_gust`
  - `rain`
  - `thunder`
  - `heartbeat`
  - `lamp_ignite`
- Procedural SFX consume **0 KB disk space** and are synthesized algorithmically on the fly.
