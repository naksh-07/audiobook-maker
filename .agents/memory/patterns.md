# Patterns & Operational Gotchas

## Environment & Audio Gotchas
- **Mobile Audio:** Termux playback uses `termux-media-player play <file.mp3>` when synced to shared storage `/storage/emulated/0/Documents/Termux/Audio/`.
- **Audio Mastering:** Direct `--master` flag or `/usr/local/bin/audio-master` applies 48kHz SOXR sinc resampling and EBU R128 loudness normalization.
- **Client Commands:**
  - `kokoro-tts status` checks health & GPU latency.
  - `kokoro-tts voices` lists 15 Goonj voices (Hindi & Indian English).
  - `kokoro-tts speak "<text>" --voice <id> [-f mp3|wav] [--master] [--play]` synthesizes speech.
  - `kokoro-tts set-url <url>` updates PC server URL in `.env`.
- **PC Server Port:** Default Kokoro/Goonj FastAPI runs on port 8880 (`http://10.236.21.128:8880`).
- **Python 3.14 Regex Gotcha:** Do NOT use inline flags `(?im)` inside grouped patterns `(|)`; pass `flags=re.IGNORECASE | re.MULTILINE` explicitly.
- **StyleTTS2 / Kokoro Chunking:** Text strings > 220 chars return HTTP 500 on GPU; auto-split on punctuation `(?<=[।\.?!])\s+` and stitch with FFmpeg.
- **M4B Chapter Injection:** Inject `FFMETADATA1` with millisecond timestamps `TIMEBASE=1/1000` via `-map_metadata 1` and `-c copy`.
- **FFmpeg Concat Demuxer on Windows:** Paths inside `concat.txt` must use forward slashes `/` (e.g., `file 'C:/path/...'`). Backslashes cause demuxer parse failures.
- **FFmpeg Resampling Engine:** Never force `aresample=resampler=soxr:osr=48000` because non-GPL/essentials Windows builds omit `libsoxr`. Use universal `aresample=osr=48000`.
- **Windows Console Unicode:** Configure `sys.stdout.reconfigure(encoding="utf-8")` to avoid `'charmap' codec can't encode characters` when printing Devanagari text.
- **Gemini Free-Tier Rate Limits:** Keep 5.0-6.0s pacing between TTS synthesis requests to stay safely under RPM quotas.
- **Gemini Safety Blocking on Fantasy Fiction:** Mature combat scenes ("swords", "blood", "kill", "striga") trigger Gemini's default safety filter, returning empty candidates or conversational refusals ("I cannot provide a direct translation..."). Always configure `safetySettings: BLOCK_NONE` across all 4 categories for literary fiction translation.
- **Linguistic Sanitizer Guardrail:** Always validate translation chunks with `validate_and_sanitize_translation()` before caching or saving. Rejects meta-patterns ("Scene Overview", "I cannot", "Would you like...") and enforces a Devanagari character purity ratio.
- **Screenplay Segment Sanitization:** In `script_builder.py`, `sanitize_screenplay_segment()` automatically purges any leaked English meta-sentences, refusal blocks, or markdown headers from audio scripts.
- **Windows Timezone Fallback (`key_manager.py`):** Python on Windows standard installations lacks `tzdata` by default. Attempting `ZoneInfo("America/Los_Angeles")` raises `ZoneInfoNotFoundError`. Always provide a fallback `timezone(timedelta(hours=-7))` for Pacific Midnight quota resets.
- **Windows CLI 8,191-Char Overflow (`cinema_audio_engine.py`):** Windows `cmd.exe` / `CreateProcess` imposes an 8,191-character command line limit. When complex audio filter graphs exceed 6,000 characters, dynamically spill `filter_complex` into a temporary `.filter` file and call FFmpeg with `-filter_complex_script <file>`.
- **Pre-Flight Voice Registry Validation (`tts_dispatcher.py`):** Before launching multi-track synthesis, invoke `validate_screenplay_speakers()` or run Gate 2 canonical auto-discovery. Reject unmapped characters with `UnregisteredSpeakerError` immediately to prevent silent voice drift to the narrator.
- **Bilingual Foley Anchor Mapping (`agent_director.py`):** To avoid the 50% dead-center pan trap on Hindi dialogue, always map Foley cues using `BILINGUAL_ANCHOR_MAP` (`दरवाजा`, `कदम`, `तलवार`, `हंसी`, etc.) in `_compute_word_level_offset()`.
- **Cumulative Timeline Drift Mitigation (`agent_director.py`):** Segment start times must accumulate both audio duration and pre-roll breath delay (`seg_duration + (seg.pre_roll_breath_ms / 1000.0)`). Omitting breath delays causes downstream Foley and BGM events to desynchronize across chapters.
- **Domestic vs. Weapon Acoustic Isolation (`acoustic_bus_matrix.py`):** Utensils, cutlery, and dishware (`fork`, `spoon`, `cup`, `plate`) must map strictly to `DOMETabl` rather than `WEAPSwd`, preventing eating/drinking scenes from sounding like metallic sword clashes.
- **Sanitizer Bracketed Tag Shield (`sanitizer.py`):** Strip bracketed acting tags (`re.sub(r"\[[^\]]+\]", "", text)`) prior to measuring Latin-to-Devanagari character purity ratios. This prevents acting tags (`[bellowing battlecry]`, `[whispers]`) from triggering false-positive rejection of valid dialogue.
- **Gemini FinishReason Parsing (`tts_dispatcher.py`):** Always guard against empty candidate arrays and parse `finishReason` (`SAFETY`, `RECITATION`, `BLOCKLIST`) with informative diagnostic feedback rather than allowing unhandled `IndexError` on `candidates[0]`.
- **Ghost Event Quarantine Invariant (`memory_store.py`):** When `commit_scene_memory()` encounters conflicting deltas, the corresponding `StoryEvent` is isolated strictly in `store.rejected_events` (and `MemoryValidationReport.rejected_event_ids`). It MUST NOT enter `store.events`, `world_state.timeline`, or character recent events; otherwise, downstream retrievers will retrieve rejected events as dramatic memories.
- **Location Condition Preservation (`memory_delta.py`):** Movement events (`CHARACTER_MOVED`) must omit the `"condition"` key in `location_state` payloads unless `meta.get("location_condition")` is explicitly provided. Blindly defaulting to `"normal"` resets damaged or destroyed locations back to pristine state upon character arrival.
- **Transitive Attack Verb Disambiguation (`events.py`):** In active transitive sentences (*"Arjun stabbed Vikram"*), the character following the attack verb is the injured victim and the preceding character is the instigator. When multiple characters appear in the clause, `SceneChangeDetector` marks `is_ambiguous=True` to safely trigger semantic LLM refinement.
- **Conservative Screenplay Performance Guidance (`memory_context.py`):** When enriching screenplay segments, never overwrite existing explicit delivery styles (inspect both `seg["delivery_style"]` and nested `seg["acting"]["delivery_style"]`). Only inject `memory_vocal_constraint` (e.g. `strained_breath`, `fatigued_low_energy`) when the line's delivery style is neutral.
- **Epistemic Strict Membership (`character_memory.py`):** A character MUST ONLY be added to `fact.known_by` if their epistemic status is `KnowledgeStatus.KNOWN`. If they merely suspect the fact (`SUSPECTED`), they are stored in `fact.character_statuses` and `character_state.suspected_facts`, preventing false-positive knowledge propagation.
- **Pre-Translation Read-Only Invariant (`translator.py`):** `_retrieve_chapter_memory_in_translator()` must remain strictly read-only and never call `commit_scene_memory()` or `store.save()`. All memory commits occur strictly in post-translation `_commit_chapter_memory_in_translator()` after translation succeeds.
- **Top-Level Screenplay Writeback (`orchestrator.py`):** Always write enriched `script_data` back to `script_file` on disk before invoking Gate 2 and `TTSDispatcher`. Otherwise, parallel worker threads will read the un-enriched script from disk, dropping `memory_vocal_constraint` tags during TTS synthesis.
- **PDF Column Gutter False-Split Invariant (`pdf_engine.py`):** In `PDFLayoutReconstructor._find_vertical_column_gutter()`, never split spans on a mere horizontal gap without validating vertical y-extent overlap and requiring parallel horizontal pairs (`same_row_pairs \ge 2`) or dense column stacks (`_is_dense_column_stack`). Indented dialogue, offset quotations, and centered epigraphs share baseline scanlines with single-column text and must not trigger false column segmentation.
- **Sacred Source vs. Speech Normalization Hygiene (`normalizer.py`, `book_model.py`):** `CanonicalBlock.raw_text` must remain completely sacred and byte-accurate to the source document. C0/C1 control code stripping (`[\x00-\x08\x0b\x0c\x0e-\x1f\x7f-\x9f]`, e.g. `\x00`, `\x07`) and soft-hyphen purges (`\u00ad`) must only occur in `CanonicalBlock.normalized_text`.
- **Gemini Vision Candidate Disqualification Invariant (`pdf_engine.py`):** In `PDFQualityAnalyzer.compare_extraction_candidates()`, never accept an escalation candidate solely because it returned a higher word count than local pypdf. Always enforce hard disqualifiers for LLM refusals (`"I cannot extract"`, `"As an AI"`), 4-gram repetition loops ($\ge 5\times$, $> 30\%$ words), replacement char (`\ufffd`) regressions, and the 45% clean word truncation guard.
- **Literary Chapter vs. Production Chunk Accessor Separation (`book_model.py`):** Always invoke `book.get_literary_chapters()` when generating authorial reader outputs, table-of-contents navigation, or M4B metadata tags to ensure multi-part chunks (`Part 1`, `Part 2`) are unified into complete parent chapters. Use `book.get_production_chunks()` or raw `book.chapters` strictly for pipeline batching and token ceiling management.
- **BookBible Hard Canon Immutability (`memory_store.py`):** `BookBible` is strictly read-only sacred canon. Dynamic relationship mutations (pronoun evolution `aap`/`tum`/`tu`, trust, respect) must NEVER write back into `BookBible.relationships`. They live strictly in `MemoryStore.relationships`.
- **Fail-Closed Memory Persistence & Verified Backup (`memory_store.py`):** Silent `except: pass` in memory loaders is permanently banned. Always create `.bak` copies before atomic replacement. When loading, validate schema version `2.0` and commit version consistency; if primary is corrupt and backup fails, raise `MemoryPersistenceError`.
- **Transactional Deep Snapshot Isolation (`memory_store.py`):** Scene commits must use `_create_snapshot()` and `_restore_snapshot()` with `model_copy(deep=True)`. Never shallow-copy dicts/lists of Pydantic models. Any failure during delta application, timeline recording, or hashing must restore the exact pre-commit snapshot.
- **Strict Event Atomicity & Disproven Belief Exemption (`memory_validator.py`):** If any delta of a multi-delta event (such as `SECRET_REVEALED`) is rejected due to a conflict, all companion deltas for that event must be purged from `accepted_deltas` and the event rejected. Additionally, deltas with status `DISPROVEN` are debunked beliefs, not secret transmissions, and must be exempted from revealer prior-knowledge checks.
- **Multi-Script Devanagari Director Cue Shield (`memory_context.py`):** Never use ASCII-only regex classes `[A-Za-z0-9]` to detect parenthetical stage directions in screenplay segments. Use script-agnostic `r"\([^)]*[^\s)]+[^)]*\)"` so Hindi stage cues like `(धीमी आवाज़ में)` are recognized and protected under Director Supremacy.
- **Container Audio Metadata Harvesting (`embedded_metadata_harvester.py`):** Always extract container tags (BWF `bext`, RIFF INFO, ID3v1/v2, Vorbis) non-destructively; never invent metadata to fill empty fields. Parse Universal Category System (UCS) tokens (`[CatID][SubCat]_[Vendor]_[FXName]`) and folder hierarchy into searchable taxonomy while preserving the verbatim dictionary dump in `raw_metadata`.
- **Multi-Scale Audio Analysis Branching (`deterministic_audio_analyzer.py`, `clap_semantic_adapter.py`, `audio_classifier_adapters.py`):** Audio duration dictates analysis strategy: micro-SFX ($<1.0\text{s}$) require centered active-region windowing with 10ms Hann micro-fades and pitch estimation guards to avoid spectral edge clicks; long-form recordings ($>30\text{s}$) require composite 3-window spectral pooling (early, mid, late), multi-window energy-weighted CLAP pooling, and AST sliding-window onset detection.
- **Consumer GPU VRAM Eviction Invariant (`sonic_harvester.py`, `sonic_model_manager.py`):** In batch sound ingestion or multi-model test runs (AST + CLAP), call `SonicModelManager().clear_vram()` and `gc.collect()` immediately after neural inference. Unmanaged PyTorch CUDA allocations across dozens of consecutive inferences cause device assertion failures and out-of-memory errors on 6GB laptop GPUs.
- **Stage 11 Premaster Decoupling (`cinema_audio_engine.py`, `mastering_engine.py`):** Stage 11 strictly outputs `_cinema_premaster.wav` and unmastered stems; it MUST NOT apply EBU R128 mastering internally. Stage 12 owns final broadcast mastering (`_cinema_master.wav`), ledger serialization, and certification.
- **Dual-Pass Linear-Phase Loudnorm Invariant (`mastering_engine.py`):** Always run FFmpeg `loudnorm` as a true dual-pass processor. Pass 1 measures `integrated_loudness`, `true_peak`, `loudness_range`, and `threshold`; Pass 2 feeds measured parameters into `loudnorm=linear=true:i=-19:tp=-1.5:lra=7.0`. Single-pass dynamic loudnorm is strictly banned as it pumps vocal backgrounds.
- **Mastering Judge Safety Envelope (`mastering_judge.py`):** `MasteringJudge` and `SceneAwareDecisionEngine` must never emit arbitrary unbounded DSP parameters. All corrective actions are strictly clamped within `SAFETY_BOUNDS` ($\pm 1.5\text{ LUFS}$, $-0.8\text{ dBTP}$, $+12\text{ Hz}$ highpass).
- **Scene-Aware Dynamics Invariants (`scene_aware_engine.py`):** Enforce `quiet != bad` and `loud != good`. Intimate/whisper scenes relax loudness targets (+1.2 LUFS) to protect dramatic tension without triggering gating; combat scenes tighten peak ceilings to -1.8 dBTP to prevent inter-sample clipping on heavy transients.
- **Reference Mastering Grounding Invariant (`reference_mastering.py`):** `REFERENCE != TRUTH`. Acoustic references are versioned benchmarks to guide bounded corrective nudges, never targets for blind audio homogenization. Inappropriate comparisons (e.g. whisper scene vs action reference) must be rejected.
- **Multi-Pass Reversion Guard (`mastering_engine.py`):** When executing iterative perceptual refinement passes (up to 2 passes), take a full file snapshot backup prior to pass 2. If pass 2 yields a lower perceptual composite score, introduces new critical issues, or causes technical QC failure, immediately restore the pass 1 audio and ledger snapshot.
- **Conservative Certification Precedence (`mastering_certification.py`):** In `MasteringCertifier`, technical QC failure (`PASS == False` on clipping, true peak > -1.0 dBTP, NaN/Inf) strictly overrides all perceptual scores, forcing `REJECTED`. Unexplained book consistency outliers ($> 3.0$ IQR) or low confidence ratings force `REVIEW_REQUIRED` with timestamped `HumanReviewItem` packaging.
- **Sliding-Window Conversational Memory in Beat-Aligned Micro-Chunking (`script_builder.py`):** When micro-chunking prose (~350 words) to prevent LLM token fatigue and dialogue swallowing, always pass `rolling_context` containing the tail 3 dialogue turns from chunk $N-1$ into chunk $N$, along with macro scene context (location, conflict, stakes) and the canonical character roster. Slicing must only occur on natural beat or paragraph boundaries, never mid-sentence.
- **Double-Safety Deterministic Quote Slicing & Gate 2 Anti-Swallow (`script_builder.py`, `gate_auditor.py`):** Even with strict LLM system prompts, generative models may occasionally leave direct quotes inside narration. `clean_screenplay_pass2()` must deterministically slice quoted substrings into discrete character dialogue turns using contextual pronoun tracking (`last_male_character`, `last_female_character`), while Gate 2 enforces a fail-closed assertion rejecting any narration containing quotation marks (`"`, `“`).
- **Era-Aware Negative Sound Bank Filtering & Acoustic Silence Preference (`sound_bank.py`, `sound_spotter.py`):** Never substitute missing acoustic assets with cross-genre approximations. In `MODERN` era scenes, medieval/fantasy keywords (`swamp`, `crypt`, `sword`, `armor`, `tavern_brawl`) are negatively filtered. If no era-appropriate asset exists in the library, fall back to natural room-tone silence rather than playing anachronistic sounds.
- **Decoupled Multi-Agent Acoustic Cue Sheet Spotting (`sound_spotter.py`, `agent_director.py`):** Do NOT overload screenplay generation with sound design directives (`sfx_cues`, `ambient_bed`, `music_cue`). Screenplay models must focus 100% on dialogue fidelity and actor emotion. Offload sound design to Stage 3.5 `SoundSpotter`, running Foley, Ambience, and Music spotters concurrently across the 100+ API key pool and outputting a dedicated `chapter_XXX_sound_script.json` for `AgentDirector`.
- **Round-Robin Anti-Hammering Key Pool Protocol (`llm_client.py`):** All Gemini generative API calls must route strictly through `PersistentKeyPool.get_key(service="text")` with true round-robin rotation (`ORDER BY last_used ASC NULLS FIRST`), 100–350ms pacing jitter, and error-based cooldowns to prevent server hammering.
- **Two-Pass Decoupled Screenplay Parser (`script_builder.py`):** Deconstruct screenplay drafting into two single-responsibility passes: Pass 1 isolates dialogue turns and attributes canonical characters; Pass 2 enriches turns with Stanislavski subtext, actioning verbs, dynamic headroom intensity, delivery styles, and spatial azimuth panning.
- **Zero Fake Creative Fallback Invariant (`beat_planner.py`, `agent_director.py`, `gate_auditor.py`):** Never substitute LLM creative work with canned Stanislavski psychological templates, 4-word domestic Foley regexes, or fake 1.0 PASS audit shortcuts. When generative models fail or are bypassed in production, the engine strictly halts (`LLMUnavailableError`) to protect dramatic truth.
