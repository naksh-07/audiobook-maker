# Audio Mastering & Speech Enhancement Skill

This skill equips Antigravity with production-grade audio mastering and DSP cleanup capabilities tailored for mobile Android (Termux) and Linux environments. It solves common AI TTS quality issues (metallic vocoder artifacts, 24kHz aliasing, sibilance, background hiss) and enforces the 48kHz Android AudioFlinger bit-perfect rule.

---

## 1. The 5-Stage Studio Vocal Chain

When processing raw AI TTS audio (e.g. Gemini TTS, ElevenLabs, Cartesia, OpenAI TTS), always pass the raw PCM or WAV through this battle-tested mastering filter chain:

```bash
ffmpeg -y -i input.wav \
  -af "highpass=f=60,arnndn=m=/root/.local/share/rnnoise/cb.rnnn,deesser=i=0.35:m=0.5:f=0.5,lowpass=f=10500,loudnorm=I=-16:TP=-1.5:LRA=11" \
  -c:a libmp3lame -b:a 320k output.mp3
```

### Stage-by-Stage Breakdown

| Stage | Filter | Purpose |
| :--- | :--- | :--- |
| **1. Rumble Cut** | `highpass=f=60` | Strips inaudible infrasound (< 50 Hz) and DC offset, saving dynamic headroom. |
| **2. Neural Denoiser** | `arnndn=m=.../cb.rnnn` (or `afftdn=nr=10:nf=-35`) | RNNoise neural recurrent network suppresses vocoder stationary noise floor and breath noise without phase distortion. Also automatically resamples to 48kHz. |
| **3. Sibilance Tamer** | `deesser=i=0.35:m=0.5:f=0.5` | Dynamically clamps harsh "s", "sh", and piercing consonant spikes between 6 kHz - 8.5 kHz. |
| **4. Nyquist Cutoff** | `lowpass=f=10500` | Eliminates the synthetic, metallic "fizz" and quantization grain generated by 24kHz neural vocoders near the 12kHz Nyquist boundary. |
| **5. EBU R128 Normalizer** | `loudnorm=I=-16:TP=-1.5:LRA=11` | Broadcast standard podcast loudness (-16 LUFS, -1.5 dB True Peak). Ensures consistent, punchy vocal delivery without digital clipping. |

## 2. Android 48,000 Hz Native Hardware Rule

> [!IMPORTANT]
> Android's internal hardware audio subsystem (`AudioTrack`, `AudioFlinger`, Qualcomm/MediaTek HAL) runs natively at **48,000 Hz**.
> Playing a 24,000 Hz file directly causes Android's fast mixer to use cheap, battery-saving linear interpolation that produces audible harshness and aliasing.
> **Always ensure the output file is 48,000 Hz** (via `arnndn` or `aresample=resampler=soxr:osr=48000`) before triggering playback on Android.

## 3. SoX (Sound eXchange) Specialized Operations

SoX is installed locally at `/usr/bin/sox` with full format support (`libsox-fmt-all`).

### A. Surgical Noise Profile Subtraction
If a recording has a specific persistent background noise or hum:
```bash
# 1. Capture 0.3s of ambient noise / silence
sox input.wav -n trim 0 0.3 noiseprof /tmp/noise.prof

# 2. Subtract the noise profile with zero speech muffling
sox input.wav cleaned.wav noisered /tmp/noise.prof 0.21
```

### B. Broadcast Vocal Compander (Studio Warmth)
```bash
sox input.wav output.wav compand 0.05,0.2 6:-60,-40,-10 -6 -90 0.1
```

## 4. Audio Quality Auditing (ffprobe & astats)

To programmatically verify audio dynamic range, noise floor, and peak levels:
```bash
ffmpeg -i mastered.mp3 -af "astats" -f null - 2>&1 | tail -n 25
```
Healthy mastering benchmarks:
- **Peak Level:** Between `-1.0 dB` and `-2.0 dB` (guarantees no inter-sample clipping).
- **RMS Level:** Between `-14.0 dB` and `-18.0 dB` (optimal vocal presence).
- **Noise Floor:** Below `-75 dB` (dead-silent background between sentences).
