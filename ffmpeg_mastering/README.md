# FFmpeg Studio Audio Mastering & DSP Suite

This module provides a production-grade DSP (Digital Signal Processing) pipeline tailored for AI speech synthesis, audiobooks, podcasts, and mobile Android (Termux) audio playback.

---

## 1. Core Architecture & Android Bit-Perfect Rule

### The 48,000 Hz Invariant
> [!IMPORTANT]
> Android's internal hardware audio subsystem (`AudioTrack`, `AudioFlinger`, Qualcomm/MediaTek HAL) runs natively at **48,000 Hz**.
> Playing a 24,000 Hz raw neural TTS stream directly forces Android's fast mixer to apply cheap, battery-saving linear interpolation that produces audible harshness and aliasing.
> **All audio generated by this pipeline is resampled via SOXR polyphase sinc to 48,000 Hz.**

---

## 2. The 5-Stage Studio Vocal Chain

```text
Raw TTS (24kHz)
      │
      ▼
[1. Highpass (60Hz)]       ──> Cuts subsonic rumble & DC offset
      │
      ▼
[2. Neural / FFT Denoise]   ──> Cleans vocoder hiss & breath noise (afftdn/arnndn)
      │
      ▼
[3. De-Esser (6-8.5kHz)]    ──> Dynamic clamp on piercing consonants
      │
      ▼
[4. Lowpass (10.5kHz)]      ──> Eliminates synthetic 12kHz Nyquist boundary fizz
      │
      ▼
[5. SOXR Sinc Resampler]    ──> High-precision polyphase sinc to 48,000 Hz
      │
      ▼
[6. EBU R128 Normalizer]    ──> Broadcast standard (-19 LUFS for Audiobook, -16 LUFS for Podcast)
```

## 3. Dynamic Sidechain Ducking Engine

In professional audiobook production, background music must never fight the human voice.
Using FFmpeg's `sidechaincompress` filter:
- When the narrator or character speaks, background music volume drops automatically by **`-16 dB`** (attenuation configurable).
- During dramatic pauses and sentence gaps, the score smoothly swells back up by `+8 dB` with a 150ms attack and 850ms release.

```bash
ffmpeg -y -i bgm.wav -i vocal.wav \
  -filter_complex "[0:a]aloop=loop=-1:size=2e+09,atrim=0:120,volume=0.35,afade=t=in:ss=0:d=2.0,afade=t=out:st=117:d=3.0[bgm_trimmed];[bgm_trimmed][1:a]sidechaincompress=threshold=0.06:ratio=8:attack=150:release=850:knee=2.5[bgm_ducked];[1:a]volume=1.0[voc_clean];[bgm_ducked][voc_clean]amix=inputs=2:duration=first[mixed];[mixed]aresample=resampler=soxr:osr=48000,loudnorm=I=-19:TP=-1.5:LRA=11[out]" \
  -map "[out]" -c:a aac -b:a 192k mastered_cinematic.m4a
```

## 4. Standalone CLI Usage

```bash
# Master a raw speech WAV to EBU R128 48kHz MP3:
python3 ffmpeg_mastering/audio_master.py input.wav -o output.mp3 -f mp3

# Apply EBU R128 audiobook broadcast standard (-19 LUFS):
python3 ffmpeg_mastering/audio_master.py chapter_raw.wav -o chapter_mastered.m4a -l -19

# Run audio telemetry & ASTS quality check:
python3 ffmpeg_mastering/audio_master.py chapter_mastered.m4a --stats
```

## 5. Healthy Mastering Benchmarks

- **True Peak:** `-1.5 dB` (guarantees no inter-sample distortion or mobile DAC clipping).
- **Integrated Loudness:** `-19 LUFS` (Audiobook standard) or `-16 LUFS` (Podcast standard).
- **Loudness Range (LRA):** `9 - 12 LU` (natural dramatic dynamics without extreme jumps).
- **Noise Floor:** `< -75 dB` (dead-silent background between sentences).
